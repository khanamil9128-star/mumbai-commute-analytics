Key Data Science Questions Answered

The core questions explored using Pandas, Seaborn, and Decision Tree Machine Learning

Which mode is fastest?

Analyzing travel times across varying distances shows how local trains dominate long distances, while metro avoids road traffic bottlenecks.

Which mode is most economical?

Local trains cost as low as ₹10–₹25 for entire suburban corridors, compared to Auto meter fares that climb steeply with distance.
