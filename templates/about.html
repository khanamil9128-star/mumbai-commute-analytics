Project Overview

Mumbai Commute Analytics — Metro vs Local vs Auto is a beginner-friendly B.Sc Data Science college project. It applies empirical data processing, exploratory data visualization, and explainable Machine Learning (Decision Tree Classifier) to model commuting patterns, financial costs, travel durations, and crowd congestion across Mumbai’s primary transit modes.

Academic Dataset Notice: "This dataset is created/simulated for academic analysis and does not represent official Mumbai transport statistics." The dataset simulates realistic operational characteristics (e.g. fare formulas, speed thresholds, peak-hour bottlenecks) solely for educational demonstration.
Technology Stack:
  • Frontend: HTML5, CSS3, Bootstrap 5, Chart.js, Vanilla JavaScript
  • Backend: Python 3, Flask Web Framework
  • Data Science: Pandas, NumPy, Matplotlib, Seaborn
  • Machine Learning: Scikit-learn (Decision Tree Classifier & Random Forest)
  • Database: MySQL & mysql-connector-python
  • Business Intelligence: Power BI Desktop & Microsoft Excel
Scope & Deliberate Limitations:
  • No commercial transport tracking or GPS live tracking.
  • No complicated deep neural networks (simplicity & explainability prioritized).
  • Predictions represent historical pattern classification, not guaranteed real-time commuter behavior.
  • Dataset reflects MMR (Mumbai Metropolitan Region) suburban journeys up to 45 km.

College Viva Preparation — Question & Answer Guide

Simple explanations in student-friendly English designed for first/second-year viva exams

Simple Explanation: Data Science is the field of study that combines mathematics, statistics, computer programming, and domain knowledge to extract meaningful patterns, insights, and predictions from raw data. In this project, we used data science to find out how Mumbai citizens commute, which transport is cheapest, and how peak hours cause delays.

Simple Explanation: Raw real-world data is always dirty—it contains duplicate entries, missing values, inconsistent casing, and impossible values (like negative costs or negative travel times). In data_processing.py, we removed duplicates, filled missing waiting times with the median, standardized names (e.g. 'metro' to 'Metro'), and removed impossible outlier rows. Remember the golden rule: "Garbage in, garbage out!" Clean data ensures accurate analysis and ML models.

Simple Explanation: Pandas provides fast, flexible tabular data structures called DataFrames. It allows us to perform SQL-like operations in Python such as grouping (groupby), filtering, aggregating averages, and handling missing data (fillna) with just one or two lines of code.

Simple Explanation: EDA is the step where a data scientist explores the data visually using charts and summary numbers before training any machine learning model. Using Matplotlib and Seaborn, we plotted travel times, costs, peak-hour effects, and crowd levels to understand relationships between distance, cost, and modes.

Simple Explanation: Machine Learning enables computers to learn patterns from historical examples without being explicitly programmed with every rule. This project is a Multi-Class Classification problem because our target variable (Transport_Mode) is a discrete categorical category with 3 classes: Metro, Local, or Auto.

Simple Explanation: Decision Trees are intuitive, rule-based, and completely explainable. Unlike neural networks (which are "black boxes"), a decision tree splits data using simple threshold questions like "Is distance > 14 km?" or "Is budget < ₹25?". It matches human decision-making and is very easy to defend in a college viva.

Simple Explanation: If we test our model on the same data it trained on, it might simply memorize the answers (overfitting). To test if the model can truly generalize to new unseen commutes, we split our data: 80% is used for teaching the model (training set), and 20% is kept aside to test its accuracy (testing set).

Simple Explanation: A confusion matrix is an N×N table that breaks down where the model made correct predictions vs where it got confused. The diagonal boxes show correct predictions (True Positives), while the off-diagonal boxes show errors (e.g. when an Auto trip was mistakenly predicted as a Metro trip).

Simple Explanation: While CSV files are useful for quick script reading, real production data is stored in relational databases. MySQL gives us structured ACID-compliant storage, indexing, and the ability to run standard SQL analytical queries (like GROUP BY Transport_Mode, AVG(Cost_INR)) to calculate benchmarks efficiently.

Simple Explanation:
  • Power BI: A specialized Business Intelligence software designed for business analysts and managers. It allows non-programmers to click, drag-and-drop, slice, filter, and explore data with zero code.
  • Flask Website: A web application built with Python. It not only displays dashboard charts but also connects to a live backend to accept user input forms, execute trained Scikit-learn Machine Learning models, and return real-time predictions.
