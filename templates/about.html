About Project & Methodology

System architecture, analytical pipeline, and project scope

Project Overview

Mumbai Commute Analytics — Metro vs Local vs Auto is an empirical Data Science study. It applies data processing, exploratory data visualization, and explainable Machine Learning (Decision Tree Classifier) to model commuting patterns, financial costs, travel durations, and crowd congestion across Mumbai’s primary transit modes.

Academic Dataset Notice: "This dataset is created/simulated for academic analysis and does not represent official Mumbai transport statistics." The dataset simulates realistic operational characteristics (e.g. fare formulas, speed thresholds, peak-hour bottlenecks) solely for educational demonstration.
Technology Stack:
  • Frontend: HTML5, CSS3, Bootstrap 5, Chart.js, Streamlit
  • Backend: Python 3, Flask Web Framework
  • Data Science: Pandas, NumPy, Matplotlib, Seaborn
  • Machine Learning: Scikit-learn (Decision Tree Classifier & Random Forest)
  • Database: MySQL & mysql-connector-python
  • Business Intelligence: Power BI Desktop & Microsoft Excel
Scope & System Limitations:
  • No commercial transport tracking or GPS live tracking.
  • Focuses on transparency and explainable rule-based machine learning.
  • Predictions represent empirical pattern classification from historical trip trade-offs.
  • Dataset reflects MMR (Mumbai Metropolitan Region) journeys up to 45 km.

Analytical Pipeline Methodology

1. Data Simulation

1,225 records simulating suburban local, metro, and auto rickshaw trips with domain-accurate speed and cost equations.

2. Data Cleaning

Deduplication, text standardization, median/mode missing value imputation, and validation of physical constraints.

3. Exploratory Analysis

Grouped aggregations, cost-per-km regressions, peak vs non-peak delay analysis, and crowd frequency cross-tabs.

4. ML Classification

Decision Tree Classifier (98.75% accuracy) providing explainable feature importances and decision rules.
